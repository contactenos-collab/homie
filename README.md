# HOMI Pamplona — web

## Configuración rápida
Todo el contenido editable está en `src/content/homi.ts`:
- `WHATSAPP_NUMBER`: número de WhatsApp Business (ej. `34600000000`, sin "+"). Mientras esté vacío, los botones abren WhatsApp sin destinatario.
- `CONTACT_EMAIL`: correo de contacto.
- `PRICES_VALIDATED`: pon `true` cuando Valeria apruebe las tarifas (oculta el aviso de precios preliminares).
- Servicios, planes, precios puntuales, FAQ (`a: null` = respuesta pendiente) y barrios.

## Pendientes antes de publicar
- Fotografías reales (portada y Valeria), reseñas verificadas.
- Número de WhatsApp, correo y datos fiscales.
- Textos legales (página /legal): aviso legal, privacidad, cookies, condiciones.
- Respuestas de FAQ sobre zonas, pagos, antelación, cancelaciones, llaves y productos.
- Validación de precios.

## Publicación
Desde Lovable: botón Publicar. Para dominio propio: Ajustes del proyecto → Dominios.
